为什么选 MusePi

为你真实的工作方式而生

01

会话即树，不是日志

每条消息都带着父节点，历史是一棵可以走的树——从任意节点分叉、回退、重新回答。上下文占用实时可见，长会话也不会迷失方向。

  • 画布地图画出完整的会话 DAG
  • 轨迹面板把同一棵树投影成时间线或分支视图
02

桌面、终端、手机，同一个大脑

桌面应用、命令行和手机背后是同一个大脑：同一批会话、同一套设置、同一批正在运行的任务。这边发起的运行，那边接着推送；换了界面，不换了上下文。

  • Android 扫码经局域网配对，端到端加密
  • SSH 友好的终端，会话与桌面完全一致
03

一台边飞边换零件的引擎

一切皆可插拔：模型提供商、工具、界面表面。它在后台盯着你的扩展目录，热重载随时生效——加能力不用重启，也不用等发版。

  • 60+ LLM 提供商，图像与视频生成内置
  • 浏览器 + computer-use、LSP/DAP、任务子代理

站在开源肩膀上，每时每刻都在往前

常见问题

你可能想先问的

现在是打磨功能阶段的免费测试，全部核心能力都开放使用，不限会话数、也不限消息数。社区版会永久免费；专业版、团队版是更远期、要等现有能力打磨成熟之后才会考虑的事——MusePi 不会悄悄把已经免费的功能变成收费墙。

桌面版覆盖 macOS（Apple Silicon）、Windows 10/11（x64 与 ARM64）、Linux（.AppImage 与 .deb，x64 与 ARM64）；终端 TUI 三平台加 WSL 通用；移动伴侣提供 Android arm64 的 .apk。它们连的是同一个后台服务，会话与设置完全一致。

是的。MusePi 支持 60+ 模型提供商，你在设置里填入自己的密钥即可使用，模型费用直接向你选定的供应商结算，MusePi 不做中转、不抽成。你也可以接本地模型。

MusePi 在你自己的机器上运行，会话、设置与历史都存在本地，默认不上传。移动伴侣通过局域网扫码配对、远程控制全程端到端加密，不经过任何第三方服务器。唯一的对外网络请求，是你自己配置的那家模型提供商。

MusePi 是一个 AI 工作台：桌面 GUI、终端、移动伴侣、常驻桌宠共享同一个后台，模型、工具、界面皆可替换。桌面与移动端、扩展系统与协作面都是我们自己做的；Agent 引擎站在开源项目 oh-my-pi 的肩膀上（详见其仓库），整体以 MIT 许可开源。
