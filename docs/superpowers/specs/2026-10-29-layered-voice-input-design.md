# 分层机主语音输入设计

## 1. 意图与依据

MusePi 需要降低旁人语音误录入，并在普通噪声环境提高转写可用性。成熟语音助手通常采用分层过滤，而不是让全部音频经过目标说话人分离。此前模型评测也证明：DPDFNet 能降噪并阻止部分误提交，但两个目标提取候选均未达到延迟或识别门槛，因此目标提取不再作为交付前置条件。

## 2. 目标、非目标与反目标

### 目标

- 麦克风按钮或快捷键继续作为明确的唤醒动作，不要求额外唤醒词。
- Silero VAD 减少非语音处理，DPDFNet 负责流式降噪，声纹嵌入负责轻量机主复核。
- `off` / `prefer` / `strict` 三种机主模式共存，默认 `off` 保持现有行为。
- `prefer` 接受高分语音；灰区只允许生成草稿且禁止自动提交；`strict` 只接受高分语音，其余要求重说。
- 声纹档案只保存模型向量，不同步、不写日志、不进入会话；用户可以重新录入和删除。
- 桌面与 TUI 共用 daemon 前端 worker 和流式分段协议，`partial` 仅作临时预览，`segment` 才进入输入框；桌面不再等整段录音结束后才显示识别文本。
- 前端稳态 RTF 不超过 0.75，流式收尾 P95 不超过 500 ms，不含 ASR 解码。

### 非目标

- 不承诺双人重叠、相似声线、仿声或极端噪声下零误判。
- 不把声纹作为身份认证或高风险操作授权依据。
- 不要求额外唤醒词、云端服务、GPU 或长期保存原始声纹录音。
- 不在本次交付目标说话人提取、多人会议分离日志或 ASR 置信度协议改造。

### 反目标

- 未确认文本先进入输入框再撤回。
- 为降低误拒而自动吸收日常语音更新声纹。
- 在实时音频回调中执行模型、I/O 或等待锁。
- 把 DPDFNet 当作目标说话人分离，或把灰区结果自动提交。

## 3. 方案选择

### A. 全量目标说话人提取

能理论上处理重叠语音，但已评测候选存在延迟、声纹失真和原始录入依赖，暂不采用。

### B. 仅唤醒词与普通 ASR

延迟低，但不能满足机主过滤，保留为 `off` 模式。

### C. 分层 VAD、降噪、声纹复核与保守提交（采用）

显式麦克风动作负责唤醒，VAD 和降噪负责音频质量，声纹负责身份倾向，提交触发器负责最后动作。重叠或不确定场景以重说/草稿降级，不追求必然分离。

## 4. 运行时结构

新增独立语音前端 worker，复用 CLI worker host、现有 sherpa 运行时和模型缓存，避免与 ASR 推理锁相互阻塞。

```text
PCM → Silero VAD/分段 → 可选 DPDFNet → 可选声纹复核 → 三态门控 → 现有 ASR
```

- VAD 分段输出保留 pre-roll，不能切断首个音素。
- DPDFNet 默认关闭，用户开启后对所有机主模式生效；前端处理失败必须明确降级，不能伪装为已增强。
- 声纹使用 3D-Speaker/ERes2Net，多个录入向量形成机主中心向量。
- 阈值由独立验证集和 MusePi 对抗集确定，不自动在线学习。
- `strict` 下只有 `accept` 进入 ASR；`prefer` 下 `accept` 正常进入，`uncertain` 可转写为草稿但禁止自动提交，`reject` 不转写。
- 未启用声纹时不加载声纹模型，也不读取声纹档案。

## 5. 声纹录入与档案

- 语音设置提供机主模式、录入、重新录入、验证和删除入口。
- 四段不同文本，每段约 4–6 秒，总有效语音至少 16 秒；另录一段独立验证文本。
- 检查静音、削波、有效长度和片段间一致性；失败只重录当前段。
- 默认只保存模型版本、向量维度、各片段向量、中心向量和阈值版本。原始音频在向量计算后立即释放。
- 档案按操作系统用户隔离；删除操作移除全部向量和临时状态。模型不兼容时要求重新录入。
- 不自动吸收后续语音；用户只能显式重新录入。

## 6. 录入界面

使用单一固定几何 `DialogFrame`，保留标题、当前朗读文本、声环、四个进度点、必要隐私信息或错误以及一个主操作。声环由真实 RMS 和有效语音进度驱动，成功时自动前进，失败只提示当前段。

不显示步骤编号、有效秒数、声纹分数或模型阶段。复用现有 `Reveal`/`HeightMorph`、`morphicons` 和 motion tokens；减少动态效果时使用静态进度条，保留辅助技术可读状态。

录音中的桌面输入区使用真实 RMS 驱动的多层声环、波形和轻微光晕，临时文本以淡入和小幅位移出现，VAD/ASR 状态控制颜色与节奏。预留临时文本区域，布局不随文本出现或消失而跳动；不使用无意义循环粒子、彩带或装饰性标签。减少动态效果时保留静态波形、进度和全部文本。

## 7. 验收

- 单元和契约测试覆盖三态门控、档案删除、模型加载、取消、音频校验、RPC 和录入状态机。
- 真实公开/合成语料覆盖中文、英文、旁人、噪声、重叠、短语音和连续录音。
- 固定对抗集不得出现非机主自动提交；干净语音相对 CER/WER 退化不超过 2%。
- 记录 CPU、线程、RTF、P50/P95、内存峰值和降级行为，不记录音频或向量。
- 若降噪在目标语料上未改善结果，不得默认开启；若声纹不稳定，严格模式必须提示重说而不是放宽阈值。

## 8. 后续实验能力

目标说话人提取仅作为重叠场景的可选实验方向。新候选必须先满足同一套延迟、内存、隐私和识别门槛，不能重新成为默认链路的前置依赖。
