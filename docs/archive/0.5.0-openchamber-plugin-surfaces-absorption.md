## 1. 双方模型对照

| 维度 | openchamber | musepi 现状 |
|---|---|---|
| 注册表 | rail registry：内置 closed mode 清单 + `plugin:${id}` 客人表面（`contributes.panel` 声明） | `EXTENSION_SLOT_DECLARATION`：7 exact + 5 前缀族；`panel.tab.<id>` 任意 id 合法；`registerComponent(slot, moduleUrl)` 代码注册 + manifest `components` 字段 |
| 可见性语义 | `availability: always \| has-content`（空表面自动隐藏，用中不消失） | 无：slot 只有挂载与否，无"有内容才显示"语义 |
| rail 顺序/隐藏 | 用户拖拽排序 + 隐藏，持久化（`contextRailOrder`/`HiddenSurfaces` + 配置 dialog，卸载扩展的 id 保留在末尾） | 拖拽交互有（RightRail + surface-tabs dnd），**无持久化、无隐藏模型** |
| 宽度记忆 | per-mode px（`widthByMode`，resize 即记； hydration 兼容旧 fraction 键） | 无 per-surface 宽度记忆（待复核：若有则是全局值） |
| zones | left/right/bottom 三区 + 拖拽移动 + keep-alive portalled panes（移动不丢 editor/terminal 状态；窄窗折叠仲裁；跨窗 storage 同步） | 右面板 + columns；无 zone 概念 |
| keep-alive 纪律 | 多实例会话面常驻挂载（portalled），单例切换重挂；状态必须可恢复 | 无明文纪律（待审计：终端/editor 切换是否丢状态） |
| 整页 | `contributes.page`：互斥主页面生命周期，不持久化，卸载/禁用/运行时切换即关 | 无整页插件表面概念（扩展中心是详情面板，非整页） |
| 状态段 | `contributes.statusSection` 进 Work Status 面板 | tool-render 卡片 + `transcript.node` 槽覆盖相近场景，基本对等 |
| 面板头 | 单 header 行 + toolbar slot（有 toolbar 时替 label，不叠第二行） | 各面板自有头形态（未统一） |
| 入口/Escape | 不变量：入口只许 rail/命令面板/内容链/composer 菜单；Escape 按 zone 关闭；portalled 菜单自理 Escape | 无成文不变量 |
| 运行域 | desktop/web MainLayout only；VS Code/mobile 各自布局 | TUI/GUI/desktop 共槽位（无此切分） |

musepi 反超项（保持不动）：`transcript.node` 按 kind 派发的 seat 粒度（比 dsh `conversation.chat.node` 更细且有 fallback 链）；manifest `components` 字段；capability-report 的挂载点诊断。

## 2. 可吸收清单

### A1 · availability 语义（小，纯前端状态）
对面：`always | has-content`（DOCUMENTATION.md:20-23）。我方 `panel.tab.*` 注册加可选 `availability`，空表面自动从 rail 隐藏、用中不消失。
验收：空扩展表面不占 rail 位；产生内容后出现，内容清空前不消失。

### A2 · rail 顺序持久化 + 隐藏模型（小，纯前端状态）
对面：`contextRailOrder` + `HiddenSurfaces` + 配置 dialog（含已卸载扩展 id 保留）。我方拖拽交互已有，只需持久化 + 隐藏开关（UI 落点：rail 尾部配置入口，复用现有 dialog 形态）。
验收：重启保留顺序与隐藏；卸载重装后顺序位还在。

### A3 · per-surface 宽度记忆（小）
对面：`widthByMode` px（DOCUMENTATION.md:24-44，含旧键兼容策略）。我方按表面记 px，resize 即存。
验收：每个表面独立记宽；布局变更不串扰。

### A4 · keep-alive vs singleton 纪律（中：先审计，后补齐）
对面：多实例会话面常驻 + 单例重挂 + 状态可恢复不变量（DOCUMENTATION.md:142-160）。我方先审计终端/editor/browser 切换是否丢状态，再按"会话面 keep-alive、单例可重挂"收敛，纪律记入 `gui-design.md`（改动章节）。
验收：切换表面不丢终端会话/editor 未存文本/滚动位置（以审计结论为准立验收）。

**审计结论（2026-10-15，✅ 已补齐并落账）**：终端 dock 首次打开即挂载永不卸载（折叠=高度归零，pty+回滚跨会话存活，`ChatView.tsx`）；浏览器 `<webview>` guest 常驻 `ManagedBrowserHost`（面板只是槽位矩形）；chat 列/侧栏跨设置页 `display:none` 常驻；**真缺口是编辑器未存文本**——`FilePane` 的 buffer 缓存是实例级 ref，随 pane 卸载一起死，files→他表面→files 丢未存文本。已修：缓存提为模块级 `unsavedBufferCache`（绝对路径键；保存/改回 saved 删条目），其余缓存协议（卸载 stash、打开恢复、dirty 守卫）不动。明确不保留（接受现状）：文件树 `scrollTop`、trajectory 列表滚动（重挂重置；进会话落尾、jump 按需滚）。纪律已记入 `gui-design.md` §5y（含 A6 入口/Escape 不变量追认）。

### A5 · 插件整页生命周期（中，M4-4.4 前置候选）
对面：`contributes.page` 互斥主页面、不持久化、卸载/禁用/运行时切换即关（DOCUMENTATION.md:13）。我方若做插件整页（M4-4.4 统一视图可能需要），照此生命周期实现，不自创语义。
验收：卸载/禁用即关整页；刷新不恢复整页。

**路线结论（2026-10-15，不做，规则预记）**：musepi 无 `contributes.page` 对等物——插件 UI 现只有面板 tab（`ext:`，随面板挂载/卸载）与扩展中心详情，无整页表面概念。A5 等 M4-4.4 设计稿定"做不做整页"；若做，生命周期照抄对面三条（互斥、不持久化、卸载/禁用/运行时切换即关），不自创语义。本轮零代码。

### A6 · 入口与 Escape 不变量（文档，随手）
对面：入口白名单 + Escape 按 zone 关（DOCUMENTATION.md:132-155）。我方记入 `gui-design.md` 改动章节，不写代码。
验收：文档合并。

**已落账（2026-10-15）**：`gui-design.md` §5y 追认两条——入口只许 rail/命令面板/内容链/composer 菜单四处；Escape 按现有顺序（弹窗捕获阶段认领、无人认领中断当前轮、portalled 菜单自理），中英双语同步。

## 3. 不吸收（附理由）

- **zones 三区拖拽**：架构量级大（zone 仲裁、跨窗同步、portalled panes）；musepi columns + rail 已够用。keep-alive（A4）可单独做，不必连 zone 一起搬。
- **面板头 toolbar slot**：musepi 各面板头形态有意分化（此前重复设计清扫的结论），不统一。
- **运行域切分**（VS Code/mobile 各自布局）：musepi TUI/GUI/desktop 共槽位是既定架构，无此需求。
