## 右栏 rail-标签绑定：代码事实与差距（M1.12 依据）

**架构（已对）**：`use-panel-tabs.ts` 头注释明写 openchamber parity——「ONE tab strip hosts every open view regardless of surface; the rail becomes a launcher — selecting a rail item opens-or-focuses that surface's tab」。tab 身份 = `surface::target`（target = 文件路径 / URL / note id 等实例地址），带每表面预算（files 12 个）与 placeholder 替换语义。`ChatView.tsx:754` 的 activeView 由活动 tab 派生。

**体验差距（小袁总观察属实）**：rail 点击不带 target → 每表面全局只有一个 rail 开的 tab；标签增殖只能靠表面内导航或 agent 打开带 target 的实例；UI 无「+ 新标签 / 中键新开 / 复制标签」入口 → 「标签页独立」只存在于模型层。

**M1.12 补全内容（小袁总 2026-09-29 批复口径）**：

1. 标签带头部「+」：按表面类型开新实例（文件→选目录、笔记→新建、浏览器→输地址）。
2. rail 纯 launcher：**悬停才高亮，不随活动标签保持点亮**（避免看起来像实例标签）；单击 = 聚焦已有标签（同视图再点 = 收起面板，沿用现有 RightRail 语义）；中键/⌘点击 = 新开实例。
3. 同表面多实例：标签身份 `surface::target`，可同时开多个不同目录/笔记/站点标签。
4. 标签右键菜单：复制标签 / 关闭其他 / 关闭；拖拽排序沿用现有 dnd-kit。
5. **布局不变**：面板内容在左、44px rail 贴客户端右缘（与 `ChatView.tsx:2507` RightRail 同构）。

**已否决**：中心浮面多表面（第一版曾拟新增 M1.12「工作台中心面」，原型评审时小袁总拍板不做——codex 等主流形态都是中心展示主会话，附加页面/预览/插件全在右侧面板标签页）。
