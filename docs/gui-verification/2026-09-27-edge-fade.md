# 全局滚动容器边缘羽化 — 验收清单（2026-09-27）

背景：用户实机反馈只有部分纵向列表有边缘羽化（fade），要求纵向 + 横向所有滚动列表统一。
本清单对应 2026-09-27 的通用化改动：共享实现在 `packages/client-core/src/lib/scroll-shadow.ts`
（`useScrollShadow` 单容器 / `useDeepScrollShadow` 子树深扫描），四方向 data 属性驱动
CSS `mask-image`；横向规则在 `packages/desktop-app/src/styles/gui-chat.css`（横向段）与
`packages/client-core/src/components/transcript/transcript.css`（横向段，含工具渲染与 shell 面板）。

统一看法：每个容器**不溢出时不应有任何羽化**；滚到一端时**该端羽化消失、另一端保留**；
滚到中间时两端羽化都在。mask 羽化内容本身，透明/玻璃容器下渐隐出底色，不残留色块；
`gui-motion-off` 不影响（静态 mask）。

## 不做/已知限制

- `mask-image` 不能双轴叠加：同一容器纵横同时溢出时只保留后写的横向羽化。现有接入容器全部为单方向滚动；不要把这两个 `:is(...)` 规则用于双轴滚动容器。
- `tr-usage` 用量行、katex、toolbar 悬浮按钮与羽化共存：按钮在滚动容器外的 wrapper 上（`.tr-table-bar` / `.tr-math-copy` 均 outside scrollport），不受 mask 影响——若发现按钮被裁切即回归。
