# ADR 0007: 转录入场、视图切换与会话列表的读法

- 状态：已接受（2026-11-24 至 2026-11-25）
- 背景：一批界面决定以日期标题的形式写进了 `docs/gui-design.md` 与 `docs/gui-implementation.md`。这两份是当前状态文档，`docs/doc-hygiene-baseline.json` 冻结了它们可以带日期标记的数量，新增决定必须落到 ADR。这里记录日期与理由，文档只留契约。
- 决定：
  - **发出的消息就地落下**（2026-11-24）。执行过渡的是转录里出现的那个气泡本身，屏幕上没有东西在飞：新出现的用户行带 `data-enter` 播一次 240ms、上浮 6px 的淡入，落定即回到常态。只有新行入场——滚回虚拟窗口的历史行本来就有 key，切会话只重建基线不重播。行按 `requestIdentity` 做 key，乐观行与 ack 后的条目是同一个 DOM 节点，所以 ack 到达时不会二次入场。
  - **全表面视图切换带关闭开关**（2026-11-25）。`.gui-view-enter` / `.gui-view-leave` / `.gui-slot-leave` 是应用里唯一一次全表面过渡（进 300ms、出 150ms，动的是 `filter: blur()`），也是唯一一支此前没有关闭开关的动画——于是没人分得清是动画卡住还是布局卡住。`gui-motion-off` 与 `prefers-reduced-motion` 现在给它 `animation: none`；退场关键帧自带 `opacity: 0` + `fill: forwards`，因为只去掉动画会让离场表面在 JS 保留它的那 150ms 里完整可见。keeper 不重播入场：靠保留 DOM 维持状态，设置栏 keeper 不动，备选页 keeper 用 160ms 透明度淡入，不再共用 `gui-view-blur-in` 把整列离屏光栅化。
  - **Vault 页是四条带加一个主体**（2026-11-24）。标题与一句用途、动作行、恰好一个主体（新增/替换表单或导入表单替换掉行与空态，而不是叠在上面）、一条脚注承担存储事实。值只写不读：遮罩输入、不可回显，值随表单消亡。
  - **会话行读作时长**（2026-11-24）。侧栏行时间是紧凑的最近活动时长（`Just now` / `5m` / `12h` / `3d` / `2w` / `4mo` / `1y`，与 Kimi Code 一致），不再是今天的钟点加更早日期的月日。`compactAge` 拥有阈值，时间列是右对齐的 `tabular-nums` 槽，单位变化不会挪动标题的截断点；模块级 30s 时钟让空闲行在两次 `session.tree` 刷新之间继续变老。
  - **会话投影由宿主计算**（2026-11-24）。需要从日志派生的会话状态由宿主算成只读模型，界面不再自己扫日志拼状态。
- 理由：决定本身没有争论点，缺的是「什么时候定的」。把日期留在当前状态文档里会持续抬升两份文档的日期标记，而它们已经从陈述现在的契约变成了堆叠变更史；日期搬进本文件后，读者仍能查到每一条决定的时间。
- 影响：`docs/gui-design.md` 与 `docs/gui-implementation.md` 对应小节去掉了标题里的日期，契约文字不变；`docs/doc-hygiene-baseline.json` 的冻结值不需要上调。
