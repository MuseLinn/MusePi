## 拟新增 / 调整的 roadmap 条目（待批复）

### 新增 M1.12「工作台中心面」（视频 parity 主缺口）

- **内容**：中心浮面从「会话单场景 + 终端标签页」升级为**容器级多表面**：代码（现有 transcript/产物视图）⇄ 看板（BoardPage 或便签面）⇄ 终端，同一容器内切换（共享元素 morph / crossfade，守 M1.10 一镜到底五原则），会话侧栏与顶栏不动。
- **依据**：宣传片 A 片 beat 3 已按此形态呈现并经小袁总两轮评审通过，等于交互设计稿已半冻结；补正式设计稿章节（并入 `gui-design.md` §5 系列）后即可动工。
- **验收**：三表面容器内切换无卸载重 mount（终端 pty 不死，已有 73c1e2310 常驻挂载先例）；切换动效符合一镜到底原则；设计稿评审通过。
- **成本**：中-大。切分建议：12a 容器与切换状态机（纯客户端）→ 12b 接入 BoardPage/终端为表面 → 12c 液态玻璃收敛。

### M3 3.7 序列补一项 3.7e「便签草图产物形态」（或作 M1.12 配套）

- **内容**：design 模式的看板产物支持自由便签（色卡 + 文字 + 手绘箭头连线），作为「发布流程/架构草图」类产物的呈现形态；落盘为 board 数据或 artifact manifest 扩展。
- **验收**：便签可增删拖连；刷新后恢复；manifest 可识别。
- **成本**：中。依赖 M1.12 容器先行（便签面是三联表面之一）。

### M1.10 批次 C 增补 composer 收敛项

- **内容**：composer 底排按宣传片形态收敛：审批胶囊、模型·深思胶囊（ModelThinkingCapsule）、语音钮、发送/停止钮的玻璃胶囊规格与排序；armed 态（语音收听/计划模式）视觉。
- **验收**：与宣传片关键帧一致；token 全取 `--glass-*` 档。
- **成本**：小。组件已存在，纯视觉与排序。

## 明确不做

- 不为视频再造第二套视觉语言——视频 token 本就取自 `gui-design.md` 液态玻璃档，收敛方向是「视频 → 产品」单向对齐。
- 桌宠/语音/通知不再立项（已实现）。
- 专家/连接器不在本清单扩范围（M4 既定）。
