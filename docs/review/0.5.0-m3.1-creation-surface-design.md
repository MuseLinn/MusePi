## 2. 参考基准吸收清单

open-design 的两套分类法值得继承：**tab = 用户启动的工作流；mode = daemon 路由指令包的方式**，刻意不一一对应（`docs/modes.md:5-27`）。

**吸收**：
- 六 tab 信息架构与各 tab 字段（§3 逐 tab 对表，含裁剪）。
- `CreateInput` 载荷形状：name / skillId / designSystemId / metadata / 工作目录。
- 模板替换语义：选模板则模板 skillId **替换**（而非组合）默认 skill（`modes.md:36-40`）。
- skill 归一：`normalizeMode` 显式声明优先、启发兜底（`skills.ts:742-760`）。
- manifest 字段深度：`version/status/supportingFiles/primary/sourceSkillId/designSystemId`（§7）。

**不吸收**：
- 115 个内置 design-templates 目录与 154 个 design-systems 资产库——资产体量是产品决策，不进本稿；Template tab 首版用会话模板替代（§3.4），designSystemId 字段先留占位（§4）。
- `SKILL_ID_ALIASES` 弃用别名表——我们没有历史包袱。
- ConnectorsSection（Live Artifact 专属）——连接器是 M4.3 的对象，本稿只留扩展位。

## 3. 信息架构：六 tab 创作面板

### 3.0 入口与层叠

创作面板是**欢迎页的全屏 overlay**（不是弹窗、不是新路由页）：欢迎页 composer 的 mode chip 选中 design/creator 时，面板以 L2 层（z 2000 带）从 composer 上方展开，Escape/收起回到欢迎页空态。理由：创作是"建会话前的配置"，语义上属于欢迎页；overlay 复用 §5u 规范的 240ms `--spring-liquid` 入场 + 140ms 出场，与设置面板（L-视图）平级不冲突。

公共区块（所有 tab 共享）：tab 条 / 项目名输入 / 工作目录选择器 / 模板轨（StartFromPicker，Blank 恒为第一卡）/ 创建按钮。控件规格见 §5。

### 3.1 Prototype（原型）

| 字段 | 控件 | 默认值 | 去向 |
|---|---|---|---|
| 平台 | PlatformPicker 多选：responsive / web-desktop / mobile-ios / mobile-android / tablet / desktop-app | responsive | metadata.platforms |
| 保真度 | FidelityPicker 双卡：wireframe / high-fidelity | high-fidelity | metadata.fidelity |
| 表面选项 | CompactToggle ×2：含落地页 / 含 OS 控件 | 关 | metadata.surfaceOptions |
| 设计系统 | DesignSystemPicker（占位，见决策点④） | 无 | designSystemId |
| 模板轨 | StartFromPicker（内置模板目录 + Blank） | Blank | skillId 替换 |

skillId：选模板 → 模板 skillId 替换默认 design skill；未选 → design 预设原样。

### 3.2 Live Artifact（实况产物）

Prototype 的特化：`kind: prototype` + `intent: live-artifact`，强制 high-fidelity（保真度选择器不渲染），标题带 Beta badge。连接器区留扩展位（M4.3 落地后填）。skillId 解析：`live-artifact` 精确 id → design 默认兜底。

### 3.3 Deck（演示稿）

| 字段 | 控件 | 默认值 | 去向 |
|---|---|---|---|
| 演讲者备注 | ToggleRow | 关 | metadata.speakerNotes |
| 模板轨 | StartFromPicker（deck 模板） | Blank | skillId 替换 |

### 3.4 Template（模板）

open-design 此处列用户经 Share 保存的 `ProjectTemplate`——我们没有 share-template 机制。**首版口径**：列"会话模板"（用户保存过的创作配置：tab + 全字段快照，存 `~/.musepi/creation-templates/<id>.json`），radio 行 + 删除确认（DialogFrame compact）；进入 tab 自动选中第一个，无模板时给空态引导（"创建原型/演示稿后可保存为模板"——保存入口放在创建成功 toast 上）。内置 115 模板目录不进首版（决策点④）。

### 3.5 Media（媒体）

tab 内二级 segmented：image / video / audio。复用现有能力（`media.providers` 设置 + generate_image / agnes_video_gen 工具）：

| 子面 | 字段 | 控件 |
|---|---|---|
| Image | 模型卡（按 provider 分组、已配置优先）+ 画幅卡（1:1/16:9/9:16/4:3/3:4）+ 提示词模板（搜索 popover + 可编辑 textarea） | MediaModelCards / AspectCards / PromptTemplatePicker |
| Video | 同 Image + 时长 select | + GuiSelect |
| Audio | 类型卡（speech/sfx）+ 模型 + 时长 + speech 时音色输入 | KindCards / GuiSelect / GuiInput |

metadata 分支记录 `mediaKind` + 对应字段。design system picker 在本 tab 不渲染。

### 3.6 Other（其他）

保留平台/设计系统控件，`skillId: null`、`kind: "other"`——不进 design skill 路由，走通用会话。

## 4. Project metadata 字段契约

metadata 是**会话级**对象，双写：daemon session 元数据（权威）+ 工作目录 `.musepi/project.json`（镜像，供恢复/分享/artifact-scan 关联）。形状：

```jsonc
{
	"version": 1,
	"kind": "prototype | deck | template | media | other",
	"intent": "live-artifact | undefined",
	"name": "项目名",
	"skillId": "解析后的主 skill（模板替换语义）",
	"designSystemId": "string | null",        // 首版恒 null（决策点④）
	"inspirationDesignSystemIds": [],          // 同上
	"platforms": ["responsive", "..."],        // prototype/other
	"fidelity": "wireframe | high-fidelity",
	"surfaceOptions": { "landingPage": false, "osWidgets": false },
	"speakerNotes": false,                     // deck
	"templateId": "string | null",             // template tab
	"media": {                                 // media tab
		"kind": "image | video | audio",
		"provider": "...", "model": "...",
		"aspect": "16:9", "durationSec": 8,
		"voice": "...", "promptTemplate": { "id": "...", "prompt": "编辑后正文" }
	},
	"createdAt": "ISO", "updatedAt": "ISO"
}
```

约束：metadata ≤16KiB（对齐 open-design 上限）；`version` 必须存在，未来迁移按 version 走；daemon `session.create` 接受 `projectMetadata` 参数并持久化，会话恢复时原样回读（GUI 创作面板再入时回填）。

## 5. 表单控件规格

全部控件从既有控件库取档，**零新视觉 token**（M1.10 纪律）：

| 控件 | 复用/新造 | 规格 |
|---|---|---|
| TabBar 六 tab | 复用设置页 tab 语言 | 选中下划线 240ms 滑动（§5s 档） |
| StartFromPicker 模板轨 | 新造（横向滚动卡轨） | 卡 160×120，Blank 恒首位；hover L2 浮起；滚动箭头 40% 渐隐遮罩 |
| PlatformPicker | 新造（多选 chip 组） | 复用 chip token（`--glass-bg` + accent 选中态） |
| FidelityPicker | 新造（双视觉卡） | 卡面 wireframe/hi-fi 示意各一张（静态 svg 内置） |
| DesignSystemPicker | 占位实现（单选 popover + 空态） | 首版数据源为空，UI 不渲染（字段留契约） |
| MediaModelCards | 新造（分组模型卡） | 复用设置→语音的模型卡样式（语音识别模型四卡） |
| AspectCards / KindCards | 新造（小卡组） | 48px 高 chip 卡 |
| PromptTemplatePicker | 新造（popover + textarea） | popover 走 §5u L3 档；textarea 复用 composer 样式 |
| ToggleRow / CompactToggle | 复用设置页开关 | — |
| 创建按钮 | 复用主按钮 | 无选择时的禁用态按 tab 规则（§3 各表） |
| 删除确认 | DialogFrame compact 档 | §5u 已转正规范 |

面板自身动效：入场 240ms `--spring-liquid`（scale 0.98→1 + opacity）、tab 切换内容区 160ms 交叉淡入（不位移）、模板轨卡片 stagger 30ms 逐项淡入（仅首次挂载）。`gui-motion-off`/`prefers-reduced-motion` 全部归零。

## 6. daemon 路由与 skill 归一（M3.3 前导契约）

- `SkillMode` 六值：`prototype | deck | template | image | video | audio`（other 不进路由）。
- 归一顺序：显式 `mode` 声明（SKILL.md frontmatter `musepi.mode`）→ 描述/正文启发 → 兜底 prototype。**显式优先于启发**，与 open-design 一致。
- 模板替换语义：创建时 `skillId = 模板 skillId ?? tab 默认 skillId`；替换不组合（prompt composer 已有 `removeBySource("mode:<id>")` 热卸载能力，无需新增机制）。
- 用户 skill 目录遮蔽内置同名 id（open-design `listSkills` 语义），我们已有 7-scope skills 扫描器，冲突优先级沿用既有约定。

## 7. artifact 契约升级方向（M3.4 前导）

我方 manifest v1（kind/renderer 四值 + entry 校验）对比 open-design 缺：`version / status / primary / supportingFiles / sourceSkillId / designSystemId / metadata`。建议升级到 v2 补齐——**但保持"无 manifest = 不可预览"的刻意契约不变**（不做 open-design 的 legacy 扩展名启发推断，坏 manifest 继续列出带 errors）。version 字段落地后旧 v1 按 version 缺省=1 兼容。具体升级在 M3.4 执行，本稿只冻结方向（决策点⑤）。

## 8. 验收标准（回归清单）

- [ ] 六 tab 各自可创建对应 kind 的设计会话，metadata 双写落盘且 daemon 可读回（M3.2）
- [ ] 选模板创建的会话走模板 skill（替换语义）；未选走 design 预设（M3.3）
- [ ] 模板 tab 空态/保存/删除闭环（M3.2）
- [ ] Media 三子面创建的会话带正确 media metadata，未配置 provider 的模型卡置灰（M3.2）

- [ ] metadata 超 16KiB 拒绝并给出语义报错（M3.2）

## 10. 决策点（待小袁总批复）

1. **入口形态**：创作面板 = 欢迎页全屏 overlay（本稿建议）vs 独立路由页 vs 弹窗。建议 overlay——语义属欢迎页、层叠与设置面板平级。
2. **Template tab 首版口径**：会话模板（用户保存的创作配置快照，`~/.musepi/creation-templates/`）替代 open-design 的 share-template + 内置 115 模板目录。若批复，内置模板库引入另立批次。
3. **Live Artifact 是否纳入首版**：open-design 标 Beta。建议纳入（成本仅 Prototype 特化 + intent 字段），连接器区留空。
4. **设计系统轴后置**：`designSystemId` 字段进 metadata 契约但首版 UI 不渲染（无数据源），3.5 独立成批。154 个 design-systems 资产是否引入、引入子集还是全量，届时单独定夺。
5. **manifest v2 升级**：补 version/status/primary/supportingFiles/sourceSkillId/designSystemId，保持"无 manifest 不可预览"契约。若批复，M3.4 按此执行。
