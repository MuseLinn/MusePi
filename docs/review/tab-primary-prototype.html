变更标注 · M1.12

1

「+」开新实例：标签带头部新增 +，按表面类型出菜单（文件→选目录、笔记→新建、浏览器→输地址）。

2

rail 只是快捷启动：悬停才高亮，不随活动标签保持点亮，避免看起来像实例标签；单击 = 聚焦该表面已有标签（同视图再点 = 收起面板，沿用现有 RightRail 语义）；中键/⌘+点击 = 新开一个实例标签。

3

同表面多实例：标签身份 surface::target（目录路径 / note id / URL），例如同时开两个不同目录的文件标签。

4

标签右键菜单：复制标签 / 关闭其他 / 关闭；拖拽排序沿用现有 dnd-kit。

✕

已否决 · 中心浮面多表面：维持 codex 式布局——主会话居中独占，终端/代码/看板等附加表面全部走右侧面板标签承载，中心面不做容器级切换。

本原型可实际交互：点 rail看聚焦闪烁、中键或 ⌘+点 rail开新实例、右键标签出菜单、拖标签换位。布局同真实客户端：面板内容在左、44px rail 贴右缘。实现层现状：use-panel-tabs.ts 模型已具备全部能力，本次只补 UI 入口与 target 传递。
