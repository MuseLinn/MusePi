## 2. dsh 清单（20 项，基线 `571902028a`）

PRESENT：工具（`ctx.tools.register/defineTool`）、hook/policy 拦截（pre/execute/post/result + guard/restrict）、MCP（one-plugin-per-server + `ctx.mcpResources.register()`）、skills（`ctx.skills` + roots + model tool）、slash（`ctx.commands`）、config UI（`ctx.settings` + configEditor + profile patch 持久化）、system prompt（`ctx.systemPrompt.section()`）、计划任务（`ctx.schedule` + jobs + due timer）、subagents/workflow（`ctx.subagents` + workflowEngine + PTC）、compaction/memory、UI（session/event + assistant-stream + followup/steer，web chat 节点渲染，客户端动态插件）、模型适配器（LlmAdapter subclass）、沙箱背书 + approval（`ctx.sandbox` backends + pre-execute ask + `ctx.approval`）、协议驱动（wire peer → `ctx.agents`，ACP 实例）、插件管理（registry/pnpm/build-approval/HMR + Web 插件页 + inventory + 动态面板 + model 侧 tool + 全套 e2e）、版本兼容预检。

PARTIAL/NO（musepi 可对齐的参照）：daemon 通用 API——无（ longevity = 常驻 Context 服务 + timers/jobs/schedule；与 musepi 一致）；插件主题能力——无（仅内置 light/dark tokens；与 musepi 一致）；非 MCP 资源注册表——无（attachment/session/projection/storage 是宿主服务；与 musepi 一致）。
