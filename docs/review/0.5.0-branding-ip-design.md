## 1. 新功能面板（what's-new，改动最大）

**现状**：`AnnouncementOverlay.tsx`（190 行）把 `changelog.startup` 的 markdown 原文整段倒进 `gui-announcement-*` 白卡（截图 3：密排 bullets、无层级、读完要十分钟）。

**改法**：

1. **结构化解析**：client-core 新增纯函数 `parseChangelogHighlights(markdown)`——按 `## [x.y.z] - date` 切段，每段提取前三条「亮点」（** 开头的条目），分类计数（Added n / Fixed n / Changed n）。解析器配契约测试（多版本段/空段/无 EN 子行/ unreleased 跳过）。daemon 侧零改动（仍传 markdown，解析在客户端）。
2. **卡面结构**（L3 overlay，§5u 弹窗契约全套：DialogFrame/portal/240ms 入/140ms 出/Escape/焦点）：
   - 头：IP 桌宠表情 sprite（PetSprite 复用，state="celebrate"）+「MusePi 更新到 v X.Y.Z」大标题 + 日期。
   - 体：本次版本亮点卡 3 张以内（图标 + 一句话标题 + ≤2 行描述，描述取 bullet 第一句、截断加「…详情」展开），下方「本次还有 N 项修复与改进」一行折叠（点开才显示完整 CHANGELOG 渲染，沿用现有 md 渲染）。
   - 旧版本：可折叠列表（标题行 = 版本号 + 日期 + 计数徽章，点开逐版本渲染），默认只展开当前版。
   - 脚：主按钮「知道了」（Enter），次按钮「查看完整日志」（外链 GitHub releases）。
3. **空态/异常**：无 markdown = 不弹（现状语义保留）；解析失败回退现行整段渲染（不白屏）。

## 2. 引导（OnboardingOverlay，1,586 行，3 步已定型）

**改法（不重构流程，只换材质与文案）**：

1. **液态玻璃化**：`gui-onboarding-backdrop`（现行最重 blur 24px）与卡体按 §5s L3 配方对齐——win32 走既有 sheen+rim 补偿（gui-chrome.css 豁免块已存在，别破坏）；步骤卡片 L2/L3 取值、步骤指示点加 `--spring-liquid` 入场（180ms chip 档）。
2. **内容人性化**（i18n 双档重写，agents 域旁新开 `onboarding` 窄域或复用现有域）：
   - 每步标题从「语言与外观」式名词改为收益句式（「先选个顺眼的语言与配色，随时能改」已有雏形，全步统一这个口吻）。
   - 第 3 步完成态三支手风琴（导入/个性化/功能速览）补一句「完成后桌面右下角会有个小家伙陪你工作」——把桌宠作为引导的收尾彩蛋，首次完成后桌宠以庆祝动画入场一次。
3. **IP 向导**：步骤卡右上角常驻小 pet sprite（眨眼 idle），步骤切换时表情随步骤变化（语言页=微笑、Provider 页=思考、完成页=庆祝）；`gui-motion-off` 下静态首帧。

## 3. 开屏启动动画（gui-splash，gui-composer.css:1145-）

**现状**：logo + `gui-splash-blink` 呼吸（已修过无限重绘画死渲染进程——**1.8s×3 后定格的约束不能回退**）+ shiny 扫光。

**改法**：

1. **IP 开屏**：开屏主角从静态 logo 换 IP 桌宠 sprite 的「苏醒」小动画（睁眼→弹跳一次→定格 logo 字样浮现），2s 内完成定格（保性能约束：动画只跑有限次数，`both` 填充定格）。
2. **玻璃底**：splash 背景从纯色改 `--glass-bg` 渐变底 + 斜向 sheen 一扫而过（一次，不循环）。
3. 进度/版本号文案下沉到画面 1/4 处，字号 token 化；win32 无 blur 照常（无 blur 元素参与）。
4. 性能红线写成注释：任何新增动画必须有限次数（iteration count 显式），禁止 infinite 常驻重绘（2026-09-14 画死渲染进程事故回归约束）。

## 4. IP 与软件图标

1. **图标**：`build/icon.svg`（及派生 icon.png/ico/icns）融入桌宠形象——用 blobstudio 管线导出的宠物正面 SVG 剪影（圆胖身体 + 眼睛）做负形/主形，保持 16px 可读（小尺寸只留单眼圆点轮廓）。多分辨率派生走既有 regen 脚本。
2. **一致性**：splash 徽标、引导卡角标、what's-new 头部三处使用同一套 sprite（PetSprite 既有组件），不另画。
3. **动效资产**：桌宠「庆祝/眨眼/思考」表情若 PetSprite 缺，用 blobstudio 补齐导出（React 组件可直接落 `packages/desktop-app/src/components/PetSprite.tsx` 旁边，不强制合并）。
