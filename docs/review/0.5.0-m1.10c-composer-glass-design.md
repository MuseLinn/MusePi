## 3. 收敛规格

### D1（C1）状态 dock chips 并入 footer-pill 家族

- **材质一元化**：todo/queue/swarm/goal/plan chips 加入 `.gui-composer-pill` 家族选择器组——glass 底 + rim inset + sheen，材质与按钮 chrome 同源。
- **颜色承载状态**（家族既有原则，arm 态先例 `gui-mode-toggle-arm--armed`）：accent 状态改 `color-mix(in oklab, var(--color-accent) 16%, var(--glass-bg))` 染色洗 + accent 文本，不再用实色 tint + hairline border。各 chip 的专属信号保持为**内容而非材质**：todo 进度条填充、swarm 运行点、queue 计数。
- **活态对齐 §5s**：agent working 期间这些 chips 处于活动态——rim 高光换 accent 色（`inset 0 1px 0 color-mix(accent …)` 变体），与「streaming → rim 换 accent」规范同一语言；冻结回落默认 rim。
- **动效入家族**：hover 升 strong + 软影、press scale .97 spring-liquid、入场 `gui-chip-in var(--gui-motion-chip)`（queue chip 已有，审计其余补齐）。
- 迁移后删除 chips 各自 ad-hoc 的 background/border/shadow 声明（保留 layout）。

### D2（C2）浮层表面收口规则（成规范）

**规则**：composer 域（及全 desktop 顺手）所有浮层表面 = `.gui-menu-popup` 配方；per-class 只留 layout。**不接受第三种方言**——`.gui-context-pop` 与 `.gui-mode-toggle-popover` 是现存仅有的两个越界者，本批收编：

- `.gui-mode-toggle-popover`：删表面声明（background/backdrop-filter/box-shadow），留 `min-width/padding/border-radius` + 行 layout。它已走 useFloatingMenu，共享表面与两阶段入场自动继承。
- `.gui-context-pop`：改走 useFloatingMenu 挂接（ContextRing 悬停读数 → 共享浮层管道，白得互斥与 two-phase enter）；若挂接成本高，退路 = 表面声明逐项对齐共享配方值（bg-overlay+glass-bg / rim inset / sheen wash / 影栈），报告中说明取舍。
- **审计清单**（施工单逐项 grep 核查）：`usage-panel.tsx` / `context-dialog.tsx` / `goal-detail-card.tsx` / `plan-panel.tsx` / `todo-panel.tsx` / `queue-panel.tsx` / `swarm-card-preview.tsx` 的容器类不得再声明 background/backdrop-filter/box-shadow；AttachMenu 两个 picker（M2-2.6 新增）一并核查。
- 零新 token：共享配方手工影栈是 desktop 方言既定值（§4 映射契约允许），不强制换 `--glass-shadow` 单声明。

### D3（C3）stats 行材质 + 输入卡备案

- **stats pill 进家族**：时间丸/用量丸 = footer-pill 家族成员（玻璃底 + rim + sheen；compact 档同材质纯读数，不改玻璃）。popover 明细 = `.gui-menu-popup` L2 天然继承；两 popover 互斥已由 floating-menu mutex 保证。
- **stats 行容器**：行容器本身 L0（无玻璃），pills 是行的 L1 成员——与按钮 chrome 同排同语言。
- **welcome 不显示 stats 行**（会话态数据，欢迎页无投影可挂）。
- **输入卡维持磨砂玻璃（小袁总 2026-09-29 批复定调）**：「我们本来就不做全透明，每一处都要是液态玻璃」——L0「输入条全无」的字面条文按 desktop 方言解释（desktop 壳输入面一律液态玻璃），`.gui-composer-frame` 磨砂卡原样维持。此条按**产品方向**记录而非「偏离」：后续新壳面（含任何新输入面）默认直接给玻璃，不走「L0 裸面 → 再补」的弯路。

### D4（C4）动效收尾

- 全 chips 补齐家族动效三件套（entrance/hover-lift/press-scale）；
- 浮层保持两阶段 transform-only 入场（**禁止**对 backdrop-filter 元素做 opacity 动画——gui-settings.css:261 注释契约，收编成 C2 验收项）；
- 降级不动：`gui-motion-off` / `prefers-reduced-motion` 短路、`[data-platform="win32"]` blur 归零 sheen+rim 补强 2% 机制全部保留。
