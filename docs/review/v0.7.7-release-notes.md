## 为什么有 --max-chars

GitHub 的 release body 上限是 125,000 字符，超过会被静默截断。线上 v0.7.7 正是如此：`gh release view v0.7.7 --json body` 取回正好 125,000 字符，正文停在「配对面板直接给出电脑地址，失败不再静默：分享面板的 6 位码旁边…分享」一句中间，其后 10 条（该条剩余部分至「浮层滚到顶/尾后不再带动背景滚动」）完全没有出现在页面上。

`--max-chars` 与 GitHub 同单位（字符），让渲染器主动在条目边界收口：保留标题、下载表、计数行、每个分类的前若干条与页脚链接，末尾一行说明还有多少条未展开，不截半句。110,000 字符给 125,000 的截断点留出 15,000 字余量；如需在页面上多留条目，可提高到约 120,000 字符。
