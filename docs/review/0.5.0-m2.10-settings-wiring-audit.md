# M2.10 桌面设置面板接线审计报告

> 对应 `docs/0.5.0-roadmap.md` M2-2.10（小袁总 2026-09-21 增设）：设置项全量盘点，三档分类（已接线 / 未接线·死按钮 / 受架构限制），验收"设置项三档清单落档；面板无死按钮"。
> 审计日期：2026-09-26。全仓只读，本报告为唯一写入物。

## 方法与证据约定

- 盘点范围：`SettingsView.tsx` 渲染的全部 27 个内置区块（`lib/settings-nav.ts:24-52` SectionId 契约）+ 扩展贡献 tab（`ext:*` 槽位，动态内容不入清单）；`shared.tsx` 按共享控件库处理（NumberStepper/hitText，无独立设置项）。
- 路径缩写（根 = `c:/Users/unive/projects/harness-engineering/musepi-omp`）：
  - `sec/` = `packages/desktop-app/src/components/settings-sections/`
  - `da/` = `packages/desktop-app/src/`，`cc/` = `packages/client-core/src/`
  - `ca/` = `packages/coding-agent/src/`，`SRV` = `ca/daemon/server.ts`
- 三大持久化通道（审计中逐一验证）：
  1. **localStorage**（GUI 本地）：`musepi-gui-*`（桌面端自有）、`omp-collab-*`（client-core 主题轴，`cc/lib/theme.ts:15-17,106-107`）、`musepi.shortcut-bindings.v1`（`da/lib/shortcut-registry.ts:174`）。
  2. **daemon RPC `settings.set`**（`SRV:5705-5764`，白名单校验 :5727-5733 → `settings.set()` + `flush()` :5761-5763）→ 落盘 `<agentDir>/config.yml`（`ca/config/settings.ts:412` + `packages/utils/src/dirs.ts:27`）；schema 驱动区块（shell/files/context/memory/interaction/subagents/voice-speech 等）全部走此通道。
  3. **域 RPC**：`models.add/remove` → `models.yml`；`providers.*` / `media` 凭据 → `agent.db` SQLite（`ca/../../packages/ai/src/auth/sqlite-credential-store.ts:525`）；`modes.save/delete` → `~/.musepi/modes/<id>.json`；`extensions.setEnabled` → config.yml `disabledExtensions` / `mcp.json`；`index.setEnabled` → `file-index.db`；Electron IPC → 主进程文件/注册表。
- 分档口径：**已接线** = 持久化 + 消费点均有 file:line 证据；schema 区块逐 key 消费未逐一追到处标注"机制级（抽样核实）"。**未接线** = 无持久化、或写了无人读、或值约定错位；"部分接线"归此档并注明缺口。**受架构限制** = 当前架构接不了（OS 层持久化、平台专属、TUI-only 交互面等），说明限制。
- 纯导航/视图态控件（tab 切换、搜索框、折叠开关）与纯动作按钮（复制、刷新、打开目录）不参与分档，单独标注"动作类/导航类"。

### 附带发现（非未接线，但建议跟进）

1. **疑似绑定错行**：custom-provider.tsx:522-542 在 adopted 行编辑器内渲染绑定手填行字段的第二组控件——建议人工确认是否复制残留。

4. **守卫不一致**：「登出全部」带 `!sessionId` 守卫（SettingsView.tsx:302）而单凭据删除无——无会话时前者静默无效。

### 结论

设置面板整体接线率高（175/192 ≈ 91%）：schema 驱动区块与 daemon 域 RPC 链路健康，localStorage 偏好绝大多数有双向消费。真正的死按钮/死设置共 12 项，其中 4 项（#1/#2/#3/#5）补接线成本极低，建议优先清掉；3 项死 schema 设置（#10/#11 + update.channel）建议按"先标注或隐藏"的路线图口径处理。达成"面板无死按钮"验收还差上述清单的清理。
